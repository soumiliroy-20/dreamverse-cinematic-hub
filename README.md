# DreamVerse Cinema

Build a modern Netflix-inspired movie discovery platform called CineVerse.

The platform supports multiple cinematic universes.

For version 1, build only the first universe called DreamVerse.

DreamVerse should have a premium pastel pink aesthetic with elegant typography, glassmorphism effects, rounded cards, subtle sparkles, soft gradients, and smooth animations.

Pages Required:

1. Landing Page

2. Login Page

3. Signup Page

4. Universe Selection Page

5. DreamVerse Homepage

6. Profile Page

7. Watchlist Page

8. Favorites Page

9. Movie Details Page

Core Features:

- Authentication-ready architecture

- Search bar

- Movie categories

- Movie cards

- Watchlist system

- Favorites system

- Responsive design

- Theme architecture for future universes

Landing Page:

- CineVerse branding

- Hero section

- Featured collections

- Trending movies

- Universe portal teaser

Universe Selection:

- DreamVerse card

- HeroVerse preview card

- Save preferred universe

DreamVerse Homepage:

- Netflix-style movie rows

- Featured banner

- Collection cards

- Continue watching section

- Recommended movies section

Technical Requirements:

- React

- TypeScript

- Tailwind CSS

- Framer Motion

- Component-based architecture

- Prepare a UniverseContext for future universe switching

Do not implement HeroVerse yet.

Only create the architecture and preview card for it.

Use placeholder images and assets so they can be replaced later.
